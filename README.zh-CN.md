# 卡点视频剪辑师

[English](README.md)

这是一个可复用的 Codex 技能：用户只需提供照片、视频和音乐，即可制作经过人工审核节拍的高质量卡点混剪。技能会先建立歌词与重拍表，再分配素材、对齐动作高潮、处理调速和字幕，最后检查实际导出的视频。

## 主要能力

- 使用 FFprobe 盘点照片、视频和音频的技术信息。
- 将自动节拍候选与人工听感审核分开，避免机械地按 BPM 均匀切镜头。
- 支持歌词标注：`/` 表示切换一段素材，`[词或音节]` 表示需要强调的区间。
- 密集重拍使用可辨认的照片或紧凑动作片段，较长间隔使用自然运动视频。
- 只对推进、碰撞等明确动作调速；海浪、自拍、走路和扫拍尽量保持自然速度。
- 横屏和竖屏素材按比例完整显示，剩余区域使用黑色填充。
- 支持简洁的中英文歌词字幕、分版本导出和成片质检。
- 原始素材始终保留在本地，不会包含在此仓库中。

## 安装

将整个文件夹复制到 Codex 的个人技能目录：

```text
~/.codex/skills/beat-sync-video-editor/
```

如果没有立即识别到技能，请重新打开一个 Codex 任务。

## 环境要求

- 可访问本地文件的 Codex
- 用于素材分析和渲染的 FFmpeg、FFprobe
- 用于运行素材清单脚本的 PowerShell
- 本地视频编辑工具；如具备 API 和公网素材地址，也可使用 CapCut Mate

## 使用方法

准备包含素材与音乐的文件夹，然后输入：

```text
使用 $beat-sync-video-editor，根据这个文件夹里的素材和音乐制作卡点视频。
先输出可审核的重拍表，确认后再渲染成片。
```

还可以提供参考视频，并补充画幅、字幕样式、排除素材、叙事顺序和目标时长等要求。

## 标准流程

1. 盘点素材；需要时按内容重命名，并保留新旧文件名对照表。
2. 分析参考视频，选择起止完整的音乐或歌词段落。
3. 核对歌词并建立非均匀重拍表。
4. 通过重拍审核视频或时间表确认每个卡点。
5. 根据间隔长度与有效动作时长分配照片和视频。
6. 使用合理调速，将动作高潮对齐到强调词接近结束的位置。
7. 分版本导出，检查声音、字幕、构图、动作连续性和密集重拍段落。

## 素材清单脚本

```powershell
.\scripts\analyze_media.ps1 -Root "D:\素材目录" -Output ".\media-inventory.json"
```

脚本会记录文件类型、时长、尺寸、横竖方向、帧率、是否包含音轨以及文件大小。素材内容和动作高潮的精确时间仍需通过画面审核确定。

## 核心剪辑原则

- 不根据 BPM 均匀分配重拍。
- 强调词持续期间都应存在有效画面变化。
- 推进完成、食物碰撞等高潮通常落在强调区间结束前约 0.20–0.30 秒。
- 优先把长素材调换到长间隔，避免长时间定格或过度慢放。
- 极短、帧数不足的片段不要设置多段突变速度。
- 音乐应在完整歌词或乐句后结束，并使用自然的渐入渐出。

## 隐私说明

本仓库仅包含可复用的技能说明和辅助脚本。用户素材、成片、重拍审核视频、字幕及项目清单均默认排除，不会被提交。
